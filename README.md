# 🐆 Panther Protocol v5.0

Zero Friction Workout App - Built with React & Vite

## Features

- 💪 Quick Start workouts
- 🔥 Fitness Daily destruction workouts
- 📊 Progress tracking with streaks
- 🧘 Full body stretch routine
- 🍗 Nutrition guide (no seed oils)

## Quick Deploy

See **QUICK-START.md** for 5-minute deployment guide.

See **DEPLOYMENT.md** for detailed step-by-step instructions.

## Development

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

## Important Notes

- **Repository Name:** If you name your GitHub repo something other than `panther`, update `vite.config.js`:
  ```javascript
  base: '/YOUR-REPO-NAME/',
  ```

- **iPhone Web App:** Already configured! Just add to home screen via Safari.

## Tech Stack

- React 18
- Vite 5
- GitHub Pages
